# Images

Last reviewed: 2026-10-19

Screenshots and artwork used by the top-level [README](../../README.md).

- `icon.svg`, `icon-256.png`: project icon (12 pitch-class spokes, after the radial
  pitch-spokes mode).
- `icon-candidates/`: the other icon concepts considered (score trail, voice towers,
  AV monogram, polar fan).
- `gallery.webp`: the README's 3×2 render grid.
- `studio-2d.webp`, `studio-3d.webp`: the README's full-studio pair (copies from `studio/`).
- `modes/`: render-stage captures, named `<demo score>_<mode>.webp`.
- `studio/`: full-studio captures (1440×900 viewport), same naming.

Captured from the dev server (`npm run dev`) with the bundled demo scores, headless
Chromium at 2× device scale, then resized and saved as WebP (quality 86).

# Developer Tools Index

Use this as a starting menu for project setup. Select only what the project needs.

## General

- Git.
- GitHub CLI.
- GitHub Actions.
- Pre-commit.
- Docker or another container runtime when useful.
- EditorConfig.
- direnv when environment switching is useful.

## Testing And Automation

- Playwright for browser automation, end-to-end tests, screenshots, and visual checks.
- pytest for Python tests.
- Vitest, Jest, or node:test for JavaScript and TypeScript tests.
- Storybook for component development where useful.

## Package And Runtime Management

- pyenv for Python version management.
- uv, pip-tools, Poetry, or Hatch for Python dependencies.
- npm, pnpm, yarn, or bun for JavaScript and TypeScript.
- asdf or mise for multi-language version management where useful.

## Documentation

- Markdown.
- MkDocs, Docusaurus, VitePress, or Sphinx when a docs site is justified.
- Mermaid for lightweight diagrams.
- ADRs for durable architecture decisions.

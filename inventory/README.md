# Inventory

This directory is a curated index of tools, skills, MCP servers, software, extensions, and source repositories that may help an AI agent scaffold or improve a project.

The inventory is not a checklist to install everything. Use it as a menu:

1. Read this file.
2. Read only topic files relevant to the project.
3. Ask the user about additional repos, tools, org standards, or constraints.
4. Choose a minimal useful set.
5. Explain why each selected item fits.

## Topic Files

- [skills-index.md](skills-index.md): skill and prompt sources to review.
- [tools-index.md](tools-index.md): general developer tools and software.
- [mcp-servers.md](mcp-servers.md): MCP and agent tool server candidates.
- [extensions-software.md](extensions-software.md): local apps, editor extensions, CLIs, and hosted services.
- [security-quality.md](security-quality.md): security, quality, dependency, and supply-chain tools.
- [python.md](python.md): Python project defaults and options.
- [frontend-design-ux.md](frontend-design-ux.md): design, UX, UI, frontend resources, design systems, and AI-assisted design tools.
- [ai-agent-platforms.md](ai-agent-platforms.md): AI coding platforms and agent workflow references.
- [source-repos-to-review.md](source-repos-to-review.md): places to record repos the user wants inspected.

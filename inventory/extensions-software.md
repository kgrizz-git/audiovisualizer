# Extensions, Software, CLIs, And Services

Last reviewed: 2026-07-11

Use this file for non-library tooling that may help the local development loop, agent workflow, design workflow, or delivery process.

## Editors And AI Coding Environments

- Codex.
- Claude Code.
- Cursor.
- VS Code.
- JetBrains IDEs.
- Xcode for Apple platform projects.

## Editor Extensions

- Language server extensions for the chosen language.
- Formatter and linter integrations.
- GitHub Pull Requests extension where useful.
- Markdown preview and linting extensions for docs-heavy projects.
- Accessibility and design token extensions where useful.

## Local Software

- Docker Desktop, Colima, or another container runtime.
- GitHub CLI.
- Figma desktop app when design sources matter.
- Claude Design for AI-assisted interface design exploration.
- Database clients appropriate to the project.
- Browser developer tools and browser profiles for test automation.

## Hosted Services

- GitHub.
- GitHub Actions.
- Dependabot.
- Snyk if already used by the user or organization.
- Figma.
- Linear, Slack, or project-management tools when the user approves connecting them.

## Selection Guidance

Choose software that improves a real feedback loop: run, test, inspect, design, secure, release, or maintain. Avoid requiring local apps or hosted services unless the project benefits enough to justify the setup burden.
